# Figma mockups

Screenshots of the Figma designs for the phone app (`frontend/`). They are the visual target for the Compose UI.

| File | What |
|---|---|
| [drive-screen.png](drive-screen.png) | Drive tab: status pill ("Driving • Monitoring"), current speed and speed limit, 3D map, 2×2 metric cards, bottom nav |
| [metric-cards-states.png](metric-cards-states.png) | Metric card component (Attention, Distraction, Eye Tracking, Speech) in GREAT / GOOD / BAD states. GREAT is green text, GOOD is blue text, BAD is a red card with white content |
| [nav-bar-states.png](nav-bar-states.png) | Bottom nav bar (Drive, Stats, Contacts, Settings), one frame per selected tab. The selected tab is blue on a pale blue pill |
| [stats-screen.png](stats-screen.png) | Stats tab: safety score ring with trip counts, weekly trend bars, behavior insights, driving patterns, recommendations |
| [contacts-wireframe.png](contacts-wireframe.png) | Contacts tab, grey wireframe only: search with mic and add, contact rows with a share toggle, "Create group" button |
